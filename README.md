# Customer Support Chatbot

A rule-based Customer Support Chatbot built using Python and NLP techniques with zero external dependencies.

## Problem Solved
Companies receive hundreds of repetitive queries daily. This chatbot automates responses and reduces manual workload.

## How It Works
User Input → NLP Preprocessor → Intent Detector → Response Mapper → Bot Reply

## Intents Covered
- Order Tracking
- Refund Policy
- Login Issues
- Payment Issues
- Product Inquiry
- Complaint Handling
- Business Hours
- Greeting / Farewell

## How to Run
python chatbot.py
